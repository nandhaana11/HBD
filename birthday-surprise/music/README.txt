MUSIC FOLDER INSTRUCTIONS:
=========================
To add your background music:
1. Choose an MP3 song you love (e.g. your best friend's favorite song or an acoustic birthday tune).
2. Rename the file to:
   birthday-song.mp3
3. Place it right here in this folder:
   birthday-surprise/music/birthday-song.mp3

NOTE:
If no audio file is provided, the website automatically plays an enchanting, gentle vintage Music Box chime melody using the Web Audio API!
